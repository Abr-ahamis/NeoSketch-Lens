# Roadmap

Estimates assume one developer, part-time, with AI agent assistance.

| Milestone | Target | Contents | Exit criteria |
|-----------|--------|----------|---------------|
| M0 Setup | Week 1 | Phase 0 | App + server skeletons run |
| M1 Sketch | Weeks 2-3 | Phase 1 | Photo in, good sketch out |
| M2 Overlay | Weeks 4-5 | Phase 2 | Overlay on live camera |
| M3 Paper fit | Weeks 5-7 | Phase 3 | 3 mm accuracy on A4 |
| M4 Projects | Week 8 | Phase 4 | Save/reopen, settings, onboarding |
| M5 Telemetry | Weeks 8-10 | Phase 5 | Crash reaches Telegram end to end |
| M6 Beta | Weeks 11-12 | Phase 6 | 5+ users, crash-free 99 percent |
| M7 v2 | After beta | Phase 7 | Auto detect, grid, export, tracking |

## Order of risk
1. Alignment accuracy and tracking (highest risk, prototype early in Python).
2. Camera/overlay performance on low-end phones.
3. Telemetry privacy compliance.
4. Store review requirements (permissions, privacy policy).

## Review points
- End of each milestone: demo on a real device, update TASKS.md, log decisions in DECISIONS.md.
